# 웹디 — 원본 기획 (설계자 브리프)

> 설계자가 준 원문이다. **여기 있는 것은 확정 요구사항이다.**
> 여기 없는 것을 구현자가 지어내면 그것은 결정이므로
> `.claude/skills/project-context/SKILL.md`에 적어 정본을 만든다.

웹디자이너 업무 기반 회사 운영 게임.

## UI
- 윈도우 컴퓨터 UI 기반
- 귀엽고 트렌디한 게임 스타일

## 능력치

**디폴트**
- 회사평판
- 회사레벨
- 소지금
- 행동력
- 정신력

**스탯**
- 디자인
- 퍼블리싱
- CS
- 피그마 숙련도
- 포토샵 숙련도
- 코딩 숙련도

숙련도가 높으면 업무 시간 단축됨.
직원은 디자인/퍼블리싱/CS 스탯만 가지고 있음.
직원은 레벨에 따라 업무 시간 단축됨.

## 기능
- **브라우저**
  - 사내시스템 접속 가능
  - 업체 사이트 접속 가능 (사용자, 관리자)
  - 채용사이트 (직원 채용 가능)
  - 업무 수주 사이트
  - 쇼핑사이트
  - 브라우저 탭 있음
  - 즐겨찾기 기능 있음
- **피그마**: 시안 제작 가능
- **포토샵**: 팝업 제작 가능
- **VS코드**: 퍼블리싱 업무 진행
- **카톡**: 클라이언트와 연락
- **네이트온**: 직원목록 확인 및 직원에게 업무지시
- **아웃룩**: 업무 요청 메일 확인, 회신 가능
- **일정**: 업무 일정 확인
- **작업물 폴더**: 시안/팝업 파일 목록 확인

## 진행
- 주단위로 실행
- 월말마다 **유지보수보고서**라는 이름으로 월정산 나옴
- 기본적으로 주중에만 일을 하되, 확률적으로 주말에 갑자기 클라이언트 연락이 오는 돌발 이벤트가 뜸.
  주말은 일할 지 안 할 지 선택 가능
- 피그마, 포토샵 월정액 결제해야 함
- 직원 채용시 월급 나가야 함
- 업무 요청은 무작위로 들어오고 데드라인이 있음

## 클라이언트 계약 방법
- 업무 수주 사이트에서 업무 수주해 옴
- 클라이언트가 메일/카톡으로 직접 업무 수주를 줌

## 직원 채용
- 브라우저 채용사이트에 공고 업로드 가능
- 직원 종류: **웹디자이너 / 웹퍼블리셔 / 디블리셔(디자인+퍼블리싱)**

## 업무 방식
- 프로그램 실행시 행동력 소모
- 행동력 내에서는 업무 몇 개든 중첩 가능 (초반에는 1개만 가능한 행동력)
- 스탯 내에서 결과물 퀄리티를 정할 수 있고, 퀄리티에 따라 필요한 행동력 다름
- 행동력은 레벨업시 추가됨
- 업무 종류: 팝업제작 및 업로드 / PPT 제작 / 사이트제작(시안, 퍼블리싱)
